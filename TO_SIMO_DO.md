# Manual Actions Required

- [ ] **Configurazione Supabase (Mobile)**: Integrare le chiavi Supabase presenti nel file `.env` della root nel progetto Flutter. 
  - Suggerimento: Usare il pacchetto `supabase_flutter` e configurare l'inizializzazione nel `main.dart`.
  - Chiavi necessarie: `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON`.
