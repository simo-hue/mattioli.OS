1. GUIDELINE 5.1.2 - DATA USE AND SHARING

1a) CONTACTS & PROTECTED DATA
Evolve does NOT access Contacts, Calendars, Photos, Camera, Mic, or Location, nor does it upload them. This is verifiable from the binary: we declare no NSContactsUsageDescription and lack the com.apple.security.personal-information.addressbook entitlement. The App Sandbox denies access outright. We only use files.user-selected.read-write for files chosen by the user (exports/profiles).

1b) UPLOADS & CONSENT
Evolve is a habit tracker. The first screen is an unskippable privacy gate detailing what is uploaded. We upload: goals, habits, mood check-ins, app settings, and basic profile data (name, email, DOB) to our Supabase servers, ONLY if the user creates an account. A user's profile picture is NOT uploaded.

1c) OTHER TRANSMISSIONS
- Sentry Crash Diagnostics: Explicit opt-in on the privacy gate (off by default).
- AI Coach: Explicit consent dialog before use. In Account mode, it goes through our OpenRouter proxy. In BYOK mode, it uses their own account. Local models (Ollama) do not transmit data.
- RevenueCat (Account mode only): Validates subscriptions. No personal data sent.

1d) PRIVATE MODE
Choosing "Continue privately on this Mac" skips account creation. Data is saved in a local encrypted database and synced end-to-end encrypted via the user's iCloud. We cannot read it.

2. REACHING THE SUBSCRIPTION SCREEN
a) Accept privacy gate, do NOT choose Private mode.
b) Sign in with demo account: wowtesting@gmail.com / TestForMePls1.
c) Press Cmd-comma for Settings > Subscription.
It displays: plans (1 month/1 year), prices, renewal terms, and links to our Privacy Policy and Apple EULA.

3. WHY TWO MODES?
Account mode syncs via our servers and runs AI Coach on our API keys. This is what the Evolve Pro subscription pays for. Private mode uses no server resources, so all features (including local AI or BYOK) are completely free. Subscriptions are hidden in Private mode because nothing is sold. Registration is not required to use the app's features (Guideline 5.1.1(v)).

4. GUIDELINE 3.1.2(c) - TERMS OF USE (EULA)
We use the standard Apple EULA. A link is in the App Description for all localizations and in-app on the Subscription screen.

5. GUIDELINE 2.1(b) - IN-APP PURCHASE PRODUCTS
Evolve is a Universal Purchase (com.simo.evolve). Both auto-renewable subscriptions are already live in the "Evolve Pro Group" for iOS.

6. com.apple.security.network.server ENTITLEMENT
We use OAuth 2.0 loopback redirect for Google sign-in. The app binds a temporary HTTP server on 127.0.0.1:39876 to receive the callback and shuts down immediately. It's not persistent, but requires this entitlement.
